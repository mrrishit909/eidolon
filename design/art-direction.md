# Art direction

## Concept: editorial couture, living fabric

1. **Chosen - Fashion magazine editorial.** Italic serif headers, generous negative space, a single red accent (Couture Red), borderless rows with hairline rules. Reference: a runway-show program or a fashion editorial spread, not a product UI.
2. Rejected - "Pattern-cutting technical drawing" (grid paper, construction lines everywhere): too literal/technical, undercuts the book's "editorial" register.
3. Rejected - Electric Thread as the dominant accent instead of Couture Red: tested, but reads too close to AURELIA's cyan/violet register in the same volume; red reserved for structural accents only.

## Palette (from the blueprint, used verbatim)
Ink `#090909`, Bone `#EAE4DA`, Chrome `#C6C8CA`, Couture Red `#B7112C`, Electric Thread `#6A5CFF`, Skin `#D7B9A3`.

## Typography
Serif display (Georgia) throughout, italic for headers and captions specifically, unlike PHANTOM's serif-but-upright register; this is the only blueprint in the volume so far using italics as a structural signal (headers = italic, body = roman).

## Component grammar
No borders except hairline 1px rules, no button backgrounds except the single primary action, generous padding. Deliberately the least "boxed" interface in the volume so far, matching an editorial rather than application register.
